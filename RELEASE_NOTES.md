# Release notes

## v0.1.0

Initial release.

- Automatic prefill from a weekly or fortnightly schedule, standard hours and public holidays.
- A diary view (week pager on mobile, full-year table on desktop) with a punch-card year overview.
- Any day can be overridden: split home blocks, office days, leave, sick days, notes.
- Multiple financial years, each with its own ATO fixed-rate cents-per-hour rate; years can be finalised (frozen).
- Configurable offices, schedule and holidays (state/region-seeded, plus custom one-off or repeating days).
- A branded accountant-ready `.xlsx` export, with live formulas and a Summary + Diary sheet.
- A guided legacy-spreadsheet import: upload, review row-by-row, commit.
- Installable PWA with an offline fallback page.
- Docker image (multi-arch, GHCR) and an Unraid Community Applications template.
